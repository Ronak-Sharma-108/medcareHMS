MedCare HMS — Hospital Management System PrototypeA browser-based Hospital Management System (HMS) prototype designed to demonstrate how hospital administrative workflows—such as patient registration, doctor directories, appointment scheduling, billing, and reporting—can be unified in a single web interface.Disclaimer: This project is built for academic and demonstrative purposes using client-side technologies and synthetic data. It is not intended for live clinical deployment or storing real patient Protected Health Information (PHI).FeaturesLanding & Role Selection UI: Informational landing page with demonstration Login/Register screens supporting role views (Administrator, Receptionist / Front Desk, Doctor, and Staff).Operational Dashboard: Centralized workspace displaying key performance indicators (Total Patients, Active Doctors, Scheduled Appointments, Revenue), recent notifications, and interactive Chart.js visualizations.Patient Management: Register, search, filter, and update patient profiles including demographics, contact info, primary complaints, allergies, and prescription notes.Doctor & Department Directory: Manage doctor profiles, specializations, departments, experience, and availability status.Appointment Scheduling: Create, confirm, and update appointment statuses (Scheduled, Confirmed, Completed, Cancelled) linking patients with doctors and departments.Billing & Invoices: Generate itemized administrative invoices, track payment status (Paid, Pending, Partial), and summarize revenue.Reports, Export & Data Portability:Generate patient, appointment, and revenue reports.One-click CSV export for spreadsheet review.Printer-friendly report layouts via browser print (printReport).Full JSON Backup & Restore using browser file APIs.Responsive Design: Adaptive layout optimized for desktops, laptops, tablets, and mobile viewports.Technology StackFrontend: HTML5, CSS3 (Flexbox & Grid), Vanilla JavaScript (ES6+)Data Visualization & Icons: Chart.js, Lucide IconsStorage & Browser APIs: localStorage, Blob, FileReader, URL.createObjectURLProject Structuremedcare-hms/

Getting StartedBecause MedCare HMS runs entirely in the browser with zero backend dependencies, setup takes seconds:Clone or Download the repository files to your local machine.Open index.html in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).Log In / Explore: Use the demonstration Login/Register screen to select a role (e.g., Administrator or Receptionist) and launch dashboard.html.Data Persistence & Storage KeysApplication records are stored locally in your browser's localStorage as serialized JSON arrays under the following keys:LocalStorage KeyDescriptionmedcarePatientsRegistered patient demographics and visit notesmedcareDoctorsDoctor profiles, specializations, and department allocationsmedcareAppointmentsScheduled appointments linking patients and doctorsmedcareInvoicesBilling records, service details, amounts, and payment statusesmedcareSettingsHospital profile details, theme preferences, and alert settingsTip: Use the Export JSON Backup feature in the Settings/Reports module to save a copy of your data before clearing browser cache.Security & Production Upgrade PathTo transition this prototype into a production-ready healthcare application, the following architectural upgrades would be required:Replace browser localStorage with a secure backend REST/GraphQL API and a normalized relational database (e.g., PostgreSQL or MySQL).Implement server-side authentication with strong password hashing and session/token management.Enforce server-side Role-Based Access Control (RBAC), input sanitization, HTTPS encryption, and comprehensive audit logging.LicenseThis project was developed for academic coursework (BCA-V Semester Minor Project).
