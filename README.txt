# MedCare HMS – Hospital Management System

## 1. About the Project

MedCare HMS is a web-based Hospital Management System developed as a BCA minor project. The main purpose of this project is to make basic hospital management work easier and more organized.

This project provides a simple interface to manage hospital-related information such as patients, doctors, appointments, invoices and reports. It also includes a login and registration page.

The project is developed using HTML, CSS and JavaScript. It uses the browser's localStorage to save demo data.

## 2. Objectives

The main objectives of this project are:

- To develop a simple hospital management website.
- To manage patient information.
- To maintain doctor details.
- To manage appointment records.
- To handle basic billing and invoice information.
- To display hospital information in a dashboard.
- To understand how HTML, CSS and JavaScript work together.

## 3. Technologies Used

The following technologies are used in this project:

- **HTML5:** Used to create the structure of web pages.
- **CSS3:** Used for designing and styling the website.
- **JavaScript:** Used to add functionality and handle user interactions.
- **LocalStorage:** Used to store demo data in the browser.
- **Chart.js:** Used to display charts and graphical information.
- **Lucide Icons:** Used to display icons in the application.

## 4. Main Features

The main features of MedCare HMS are:

1. **Login and Registration:** Provides a login and registration interface.
2. **Dashboard:** Displays an overview of hospital information.
3. **Patient Management:** Allows users to view and manage patient records.
4. **Doctor Management:** Displays doctor details and specializations.
5. **Appointment Management:** Helps manage appointment information.
6. **Billing and Invoices:** Provides basic invoice and billing management features.
7. **Reports:** Displays hospital-related reports.
8. **Settings:** Provides application settings.
9. **Dark Mode:** Allows users to switch between light and dark themes.
10. **Data Export:** Supports exporting selected information and reports.

## 5. Project Folder Structure

The project contains the following files:

```text
MedCare_HMS/
│
├── dashboard.html
├── index.html
├── script.js
├── style.css
└── README.md
```

**File Description:**

- `dashboard.html` – Contains the landing page with login and registration forms.
- `index.html` – Contains the main Hospital Management System application.
- `script.js` – Contains JavaScript functions used for application functionality.
- `style.css` – Contains the external CSS styling.
- `README.md` – Contains information and instructions about the project.

## 6. How to Run the Project

Follow these steps to run the project:

1. Download or extract the project folder.
2. Open the project folder.
3. Make sure all the project files are in the same folder.
4. Open `dashboard.html` in a web browser.
5. Use the registration or login interface.
6. After login, the main application page will open.
7. Explore the different sections of the Hospital Management System.

No separate installation is required to run this frontend project.

## 7. Data Storage

This project uses JavaScript localStorage to store demo information in the browser.

The data remains available in the same browser unless the browser storage is cleared. Since the project does not currently use a backend or database, the information is not stored on a central server.

## 8. Limitations

Some limitations of the current project are:

- The project is currently frontend-based.
- It does not use a server-side programming language.
- It does not have a MySQL or other database connection.
- Data is stored locally in the browser.
- Data is not automatically shared between different computers or browsers.

## 9. Future Scope

In the future, this project can be improved by adding:

- PHP or Node.js for backend development.
- MySQL database for permanent data storage.
- Proper user authentication.
- Different access levels for admin, doctors and staff.
- Online appointment booking.
- Improved security and data backup facilities.

## 10. Conclusion

MedCare HMS is a minor project developed to understand the basic concepts of web development. Through this project, I learned how to create web pages using HTML, design them using CSS and add functionality using JavaScript.

The project helped me understand how different sections of a hospital management system can be organized in a single web application. It can be further improved by connecting it with a backend and database.
